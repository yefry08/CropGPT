# videomaker (desktop)

A Python desktop app for vertical (9:16) explainer reels in two styles: **paper collage** and **explicativo** (the look of
animated news explainers: clean paper, highlighter headlines, black-and-white cut-outs, hand-drawn notes, count-up numbers). **The video is drawn by code**
(`vmk/film.py`, cairo): backgrounds, cut-out drawings, label tapes, flip tiles, stamps, torn-paper captions and the
whip-pan between scenes. **The only AI is your voice**, generated by the Voicebox app on your own computer.

## Install

1. Python 3.10+ and **ffmpeg** on the PATH (Windows: `winget install ffmpeg`; macOS: `brew install ffmpeg`).
2. The **Voicebox** app open, with your cloned-voice profile.
3. Run `videomaker.bat` (Windows) or `./videomaker.sh` (macOS/Linux). The first run creates `.venv` and installs
   `requirements.txt` (PySide6, pycairo, Pillow). Or by hand: `pip install -r requirements.txt` and `python videomaker_app.py`.

## Use

1. **Publicación y ajustes** → choose the *Estilo visual*; *Buscar perfiles en Voicebox* → choose your voice; set the language and pace.
2. **Escenas**: one scene per paragraph of narration. Each scene has a background and one or more *momentos* (beats);
   each beat lists its pieces (cinta, fichas, sello, texto, dibujo) that pop in one after another. Select a row and click
   the preview to place it. *Pronunciación* lets you respell names for the voice (e.g. «Antrópic»).
3. *Generar voz* per scene (or *Generar todas las voces*); *Otra toma* tries another seed; *Escuchar* plays it.
   Scene lengths follow the voice.
4. *Exportar video* writes `<title>.mp4` (1080×1920, 24 fps, H.264 + AAC) and `descripcion.md` into the project folder.

A project is a folder with `project.json` and `audio/`. `samples/neveras` is a complete example (generate its voices first).

## Code

- `vmk/draw.py` palette, shapes, ink with the paper-border silhouette, halftone, text, shadowed sprites
- `vmk/props.py` 51 generic drawings (no logos or real people)
- `vmk/explainer.py` the explicativo style (headline swipe, counters, annotations, lower-third captions, push transition)
- `vmk/film.py` scenes → frames, piped as raw video to ffmpeg (~12 ms per frame)
- `vmk/voice.py` Voicebox API client (`/profiles`, `/generate`, `/history/<id>`, `/audio/<id>`) and audio clean-up
- `vmk/project.py` project files, timing, `descripcion.md`
- `videomaker_app.py` the PySide6 window
