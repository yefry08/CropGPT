## 4. TEACHER TRAINING OUTLINE

### Session 1: Fundamentals (4 hours)

**Part A: Drone Basics (2h)**
- History + applications of drones
- Hardware: motors, propellers, sensors, batteries
- Safety regulations in Paraguay (DINAC basics)
- Insurance + liability

**Part B: Hands-on Flight (2h)**
- Assembly practice
- Simulator training (DJI Simulator)
- First flights indoors
- Troubleshooting common issues

### Session 2: Coding & Automation (4 hours)

**Part A: Block-based Coding (2h)**
- DJI Tello SDK overview
- Blockly programming interface
- First autonomous programs
- Examples: square flight, altitude control

**Part B: Python Basics (2h)**
- Python environment setup
- DJI SDK library
- Sample code walkthrough
- Debugging + testing

### Session 3: Teaching Methodology (2 hours)

- How to teach drone piloting to beginners
- Managing classroom dynamics + safety
- Common student mistakes + corrections
- Facilitation of group work

**Post-training Support**:
- Email support (48-hour response)
- Monthly check-in calls
- Access to curriculum updates
- Peer community (other teacher networks)
